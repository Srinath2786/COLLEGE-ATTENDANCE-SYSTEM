## 🎓 ESEC Attendance Management System

> A modern web-based **College Attendance and Lab Management System** developed using **PHP, MySQL, HTML, CSS, and JavaScript**. The application helps educational institutions efficiently manage students, laboratory sessions, attendance records, and reports through a secure role-based dashboard.

---

## 📖 Project Overview

The **ESEC Attendance Management System** is designed to automate attendance management for colleges and educational institutions. It enables administrators to manage students, classes, subjects, laboratory schedules, and attendance records while allowing students to securely track their attendance during scheduled lab sessions.

The system records detailed attendance information, including login and logout times, IP address, system name, attendance mode, and timestamps, ensuring accurate and reliable attendance tracking.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Srinath2786/COLLEGE-ATTENDANCE-SYSTEM.git
```

### 2. Start XAMPP

* Start Apache
* Start MySQL

### 3. Move the Project

Copy the project folder into:

```
xampp/htdocs/
```

### 4. Import the Database

* Open phpMyAdmin
* Create a new database
* Import the provided SQL file

### 5. Launch the Application

Open your browser:

```
http://localhost/COLLEGE-ATTENDANCE-SYSTEM
```
